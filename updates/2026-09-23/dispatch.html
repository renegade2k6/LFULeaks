What This Update Actually Means

Live

Halloween 2026 Battle Pass

New battle pass entry confirmed live: bg_bp_Halloween2026 and matching tab banner tied directly to the Activity panel table. This is a real, scheduled event, not just leftover art.

Live

Halloween Cosmetics & Store

Bunch of Halloween-tagged assets are actually wired into data this time: honor icons, a pumpkin box icon, a Halloween store icon, a nameplate/title icon, a chat bubble icon, and a vehicle skin image (wanshenjie2026 line). Points to a themed cosmetic set and a limited storefront alongside the pass.

One avatar frame icon (ICON_Item_Frame_wanshenjie2026) is also linked, so a matching frame reward is part of this set.

Staged

Second Frame Asset

A related frame image (UI_Frame_wanshenjie2026_b) showed up but isn't linked to any data yet. Could be a second reward tier for the same set, could be unused. Not confirmed.

Staged

Unlinked Halloween Art

Lot of extra Halloween-themed images this update with no data hooks yet: a gift pack background, a jungle collection background, a 'Nutcracker' tab banner, store backgrounds, and six tab variants for something called fuhuojie (revival festival). Names suggest more event screens are coming, but none of it is live yet — treat as a maybe.

Partial

Class Level Rows Cycling Back

Commando, Archer, and other class level-up rows (roughly levels 1-11) changed again this update. These are the usual progression/balance tables recurring, not new content.
